# Auralis Flow

> Protótipo desenvolvido no Hackathon SEBRAE 2025 — Anápolis, GO

## Sobre o projeto

O Auralis Flow é uma solução B2B focada em saúde mental de adolescentes. A plataforma combina monitoramento contínuo e visualização de padrões emocionais para auxiliar profissionais de saúde a identificar sinais de risco antes que se tornem crises.

Desenvolvido em ambiente de hackathon, sob pressão de tempo e com apresentação ao vivo para banca avaliadora.

## Telas

Este repositório contém as telas apresentadas no pitch do hackathon.

## Stack utilizada

- React + Vite
- Tailwind CSS
- Python + ReportLab (geração de relatórios PDF)
- Deploy: Vercel
